FRAKTURKALENDERN – BYT LÖSENORD
================================

NY FUNKTION
-----------
När någon har loggat in visas knappen "Byt lösenord" i övre högra delen av kalendern.
Användaren anger:
  1. Nuvarande lösenord.
  2. Nytt lösenord (minst 8 tecken).
  3. Nytt lösenord igen.

Appen kontrollerar aktuellt lösenord mot Firebase Authentication och uppdaterar
lösenordet säkert via Firebase. Kontot och användarnamnet ändras inte. Funktionen
fungerar även för väntande konton; man måste dock vara inloggad.

INSTALLATION (endast GitHub)
---------------------------
1. Öppna https://github.com/erik94pr/frakturregisterystad
2. Öppna Add file -> Upload files.
3. Ladda upp dessa TRE filer från ZIP-paketet, till huvudmappen (root):
   - app.js
   - index.html
   - style.css
4. Bekräfta att befintliga filer ersätts och klicka Commit changes.
5. Öppna https://erik94pr.github.io/frakturregisterystad/
6. Uppdatera sidan med Ctrl+F5 om den gamla versionen visas.

Firebase-inställningar, Firestore-regler, funktionerna för administratör och
registreringar behöver INTE ändras. Ladda inte upp ZIP-filen direkt: packa upp.

TESTA
-----
1. Logga in på kalendern med ett befintligt konto.
2. Klicka "Byt lösenord".
3. Skriv det nuvarande lösenordet och det nya två gånger.
4. Klicka "Spara nytt lösenord".
5. Logga ut och testa att logga in med det nya lösenordet.

BEGRÄNSNING
-----------
Detta fungerar bara om användaren vet sitt nuvarande lösenord.
Den frivilliga mejladressen i användarprofilen är fortfarande endast
kontaktuppgift, INTE automatisk lösenordsåterställning.
En användare som har glömt sitt lösenord behöver en separat lösning.

SÄKERHET
--------
Lösenorden sparas inte i Firestore, kalendern eller GitHub; Firebase
Authentication hanterar ändringen. Nuvarande lösenord måste anges för
att Firebase ska godkänna lösenordsbytet.
